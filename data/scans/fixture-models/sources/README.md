# fixture-models sources

Straight-on photos of the real study lounge, for `fixture-models/make.ts`. Each was rendered from a chair
Detail Capture (`real-scans/POLYCAM_CHAIR_1.glb`, `_2.glb`, unlit, so its pixels are the capture's own),
with an orthographic camera and clipping planes that keep only the surface wanted, then cropped clean.
