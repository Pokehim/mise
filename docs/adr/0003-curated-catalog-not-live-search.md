# The Catalog is curated in advance, not searched live on the web

The Catalog is a hand-picked set of roughly 100–200 furniture and decor items, prepared before the demo. It is mostly drawn from Amazon Berkeley Objects (CC BY 4.0), plus Khronos glTF sample models and Poly Haven models. It is not a live search of the web. No live source returns furniture models with trustworthy real-world dimensions, and Resize depends on dimensions. When a category is missing from the Catalog, text-to-3D generation fills the gap.

## Consequences

- ABO has no prices, so any cost shown is a clearly labeled estimate.
- 99.4% of ABO models have a single baked material, so recoloring a Piece tints the whole object, and changing a Piece's material means swapping it for a similar item.
- The Catalog needs ABO attribution in the app.
