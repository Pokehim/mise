# The landing page's 16 rooms

The Designs behind the 16 rooms on the landing page (`web/src/pages/landing/rooms.ts`): Claude made each of the study lounge (`lounge`) from a one-line Brief, three per Brief, with Generate. They are kept here, not in `data/designs`, so the Scans page lists only the lounge's own Designs, and so that each room can later be animated assembling itself Edit by Edit.

To open one in the editor, copy it into `data/designs/`, then go to `/d/<id>`. Each image is that Design from the door, taken with `/d/<id>?shot=door`, then cropped to 4:3.
